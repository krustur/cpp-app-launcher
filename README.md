# cpp-app-launcher

Minimal standalone Windows launcher library and example application.

## Files

- `AppLauncher.h` / `AppLauncher.cpp`: self-updating launcher implementation
- `SimpleJson.h` / `SimpleJson.cpp`: minimal top-level JSON string/int reader
- `MyApp.rc`: fallback embedded `manifest.json` and `config.json` resources
- `ExampleUsage.cpp`: example `wWinMain` integration
- `CMakeLists.txt`: simple Windows build definition
